# Conventions de commit

Format inspiré de Conventional Commits :

```
feat(web): aperçu carte wallet interactif
fix(billing): idempotence webhook paiement
docs(arch): clarifier flux PassKit
chore(repo): ajouter .env.example
```

Scopes usuels : `web`, `api`, `db`, `shared`, `wallet`, `billing`, `infra`, `arch`.
